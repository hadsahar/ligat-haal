## איך זה עובד

**גוררים.** רשימה של 14 קבוצות, ואתם קובעים את הסדר. מי שלמעלה — אלופה.
שתי התחתונות — יורדות לליגה הלאומית. אפשר לגרור מהידית, או להזיז שורה בחצים ▲▼
אם רוצים דיוק.

**בוחרים זוכת גביע.** גביע המדינה מזכה במקום באירופה גם קבוצה שלא סיימה
גבוה בליגה — ולכן אפשר לבחור מתוך 30 קבוצות: 14 של ליגת העל ו-16 של
הליגה הלאומית, שגם הן משתתפות בגביע ויכולות לזכות בו.

**שולחים פעם אחת.** ממלאים שם, לוחצים שלח, וזהו. אין עריכה אחר כך —
אז כדאי לחשוב לפני.

**ההגשות נסגרות ב-31 באוגוסט בחצות.** יש שעון שסופר לאחור בראש העמוד.
אחרי זה הטופס ננעל ונשארות רק התוצאות.

> הרשימה מוגרלת מחדש לכל אחד, כדי שהסדר ההתחלתי לא ישפיע על הניחוש.

## מה רואים בעמוד התוצאות

| | |
|---|---|
| 🏆 **מי האלופה** | כמה אנשים שמו כל קבוצה במקום הראשון |
| 🏆 **זוכת הגביע** | ההימורים על הגביע, כולל מי העז לבחור קבוצה מהליגה הלאומית |
| 🌍 **המירוץ לאירופה** | מי מעפילה בפועל — לפי הכלל האמיתי (ראו למטה) |
| 📋 **הטבלה המשוקללת** | ממוצע המיקומים של כל קבוצה — התחזית של הקבוצה כולה |
| 📈 **התפלגות** | לוחצים על קבוצה ורואים בדיוק איפה כולם מיקמו אותה |
| 🌡️ **מפת חום** | כל הקבוצות מול כל המיקומים במבט אחד. אלכסון נקי = הסכמה מלאה |
| 🔥 **מחלוקות** | הקבוצות שעליהן הכי פחות הסכמתם |
| 🤝 **הסכמות** | ובצד השני — הקבוצות שכמעט כולם מיקמו אותו דבר |
| ⚔️ **ראש בראש** | בוחרים שתי קבוצות ורואים מי מסיימת מעל מי, ובאיזה רוב |
| 💪 **קריאות אמיצות** | ההימורים הבודדים שהכי רחוקים מדעת הרוב |
| 🌊 **עם הזרם או נגדו** | כמה הטבלה של כל אחד דומה לתחזית הקבוצתית |
| 👯 **מי חושב כמוך** | הזוגות שהטבלאות שלהם כמעט זהות |
| 👥 **הניחושים המלאים** | הטבלה של כל אחד ואחת, פתוחה לצפייה |

> חלק מהפילוחים האישיים נפתחים רק מ-3 משתתפים ומעלה — לפני זה אין להם משמעות.

### איך נספרת ההעפלה לאירופה

3 המקומות הראשונים בליגה מעפילים, ובנוסף זוכת גביע המדינה.
**אם זוכת הגביע כבר נמצאת בשלישייה, הכרטיס שלה מחליק למקום הרביעי.**
כך שכל ניחוש מייצר בדיוק 4 מעפילות — והעמוד מחשב את זה לפי הכלל הזה,
כולל המקרה שבו זוכת הגביע היא בכלל קבוצה מהליגה הלאומית.

הכל מתעדכן בזמן אמת — כל ניחוש חדש משנה מיד את הסטטיסטיקות.

## הוגן?

**הסדר ההתחלתי אקראי** לכל משתתף, כדי לא לרמוז על תשובה.

**אי אפשר לערוך או למחוק** ניחוש אחרי שנשלח — לא את שלכם ולא של אף אחד אחר.
זה נאכף בבסיס הנתונים עצמו, לא רק בדפדפן.

**ההגשות נחסמות אוטומטית** ברגע שהדדליין עובר, גם אם מישהו ישאיר את
העמוד פתוח וינסה לשלוח מאוחר יותר.

מניעת הגשה כפולה נשענת על נעילה בדפדפן — היא עוצרת טעויות, אבל מי שמאוד
ירצה יוכל לעקוף אותה. זו קבוצת חברים, אז סומכים אחד על השני. 🤝

## מאחורי הקלעים

עמוד סטטי לגמרי — HTML, CSS ו-JavaScript, בלי שום ספרייה חיצונית ובלי שלב build.
הניחושים נשמרים ב-[Supabase](https://supabase.com), עם הרשאות שמאפשרות
רק קריאה והוספה, ורק עד הדדליין.

```
index.html    טופס הניחוש
stats.html    עמוד התוצאות
assets/       css + js
supabase/     סכמת בסיס הנתונים
```

הגרירה בנויה על Pointer Events, כך שהיא עובדת זהה בעכבר ובמגע.
העיצוב RTL ומותאם קודם כל למובייל — רוב האנשים ייכנסו מהטלפון.
