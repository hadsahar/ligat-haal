## איך זה עובד

**גוררים.** רשימה של 14 קבוצות, ואתם קובעים את הסדר. מי שלמעלה — אלופה.
שתי התחתונות — יורדות לליגה הלאומית. אפשר לגרור מהידית, או להזיז שורה בחצים ▲▼
אם רוצים דיוק.

**שולחים פעם אחת.** ממלאים שם, לוחצים שלח, וזהו. אין עריכה אחר כך —
אז כדאי לחשוב לפני.

**ההגשות נסגרות ב-31 באוגוסט בחצות.** יש שעון שסופר לאחור בראש העמוד.
אחרי זה הטופס ננעל ונשארות רק התוצאות.

> הרשימה מוגרלת מחדש לכל אחד, כדי שהסדר ההתחלתי לא ישפיע על הניחוש.

## הוגן?

**הסדר ההתחלתי אקראי** לכל משתתף, כדי לא לרמוז על תשובה.

**אי אפשר לערוך או למחוק** ניחוש אחרי שנשלח — לא את שלכם ולא של אף אחד אחר.
זה נאכף בבסיס הנתונים עצמו, לא רק בדפדפן.

**ההגשות נחסמות אוטומטית** ברגע שהדדליין עובר, גם אם מישהו ישאיר את
העמוד פתוח וינסה לשלוח מאוחר יותר.

מניעת הגשה כפולה נשענת על נעילה בדפדפן — היא עוצרת טעויות, אבל מי שמאוד
ירצה יוכל לעקוף אותה. זו קבוצת חברים, אז סומכים אחד על השני. 🤝

## מאחורי הקלעים

עמוד סטטי לגמרי — HTML, CSS ו-JavaScript, בלי שום ספרייה חיצונית ובלי שלב build.
הניחושים נשמרים ב-[Supabase](https://supabase.com), עם הרשאות שמאפשרות
רק קריאה והוספה, ורק עד הדדליין.

```
index.html    טופס הניחוש
stats.html    עמוד התוצאות
assets/       css + js
supabase/     סכמת בסיס הנתונים
```

הגרירה בנויה על Pointer Events, כך שהיא עובדת זהה בעכבר ובמגע.
העיצוב RTL ומותאם קודם כל למובייל — רוב האנשים ייכנסו מהטלפון.
